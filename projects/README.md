# Projects

Each directory contains one self-contained ESP32 project.

Current scaffold:

- `esp32-wifi-test/` — Wi-Fi/AP/network experiments; destination for the existing local project.
- `esp32-chatbot/` — ESP32 chatbot / AI client experiments.
- `esp32-sensors/` — sensor and telemetry projects.
- `esp32-display/` — OLED/LCD/UI experiments.
- `esp32-robot/` — robotics, actuators, and ESP32 ↔ Raspberry Pi work.
